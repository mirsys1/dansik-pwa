지금의 에너지 사용

현재 단식 구간의 소비를 따로 보여줘요. 단식이 어제 시작됐다면 어제 소비도 포함돼요.

시간·신체 정보를 사용해 모델로 계산한 값이에요. 실제 지방 사용량이나 체지방 감소를 측정한 값은 아니며, 식사 구성·활동 등에 따라 달라져요.

계산 기준 보기

소비량은 현재 설정한 신체·활동 정보와 기록 시간을 사용해 계산해요. 지방 활용 표시는 시간 구간별 가정이며 개인의 대사 변화를 확인한 결과는 아니에요.

지난 기록도 현재 신체 설정으로 계산해요. 그래프는 식사 간격이 끝난 날짜의 최장 기록이며, 기록하지 않은 식사는 반영되지 않아요. 중지한 시간은 현재 타이머에서 제외돼요.

나에게 맞는 단식

신체 및 활동 정보 (칼로리 계산)

성별·나이·키·몸무게와 활동 수준에 맞춰 단식 단계별 소비 칼로리를 자동 계산해요.

시간

8~24시간 중 편안한 목표를 직접 정하세요.

자동은 Windows 표시 언어를 따라요.

Windows 시계가 다른 지역으로 되어 있어도 선택한 시간대의 날짜와 시각을 사용해요.

앱 전체의 배경과 강조 색상을 바꿔요.

기록은 이 컴퓨터에만 저장돼요.

계정이나 인터넷 연결 없이 사용할 수 있어요.

가져오기 방식

바꾼 직후에는 되돌리기로 이전 기록을 복구할 수 있어요.

단식 타이머 사용 방법

처음 사용하기

  1. 식사를 마치면 아침·점심·저녁·간식 버튼을 눌러요. 누른 시각이 기록돼요.
  2. 가운데 타이머가 마지막 식사 이후 시간을 보여 줘요.
  3. 잘못 눌렀다면 되돌리기나 Ctrl + Z를 눌러요.

기록 보관

기록은 이 컴퓨터의 %LOCALAPPDATA%\DansikTimer\data에만 저장돼요. 도움말 메뉴의 기록 폴더 열기로 바로 열 수 있어요. 설정에서 JSON 백업을 내보내고 불러올 수 있어요.

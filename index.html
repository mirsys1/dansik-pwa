        화면·언어밝기·색상·언어·시간대

        화면

        앱 전체의 배경과 강조 색상을 바꿔요.

        24시간 동안 색이 이어지고, 하루가 지나면 다시 시작해요.

        언어·시간대

        자동은 기기의 표시 언어를 따라요.

        선택한 시간대를 기준으로 기록의 날짜와 시각을 표시해요.

        기록·동기화백업, 기기 동기화

        기록 백업

        기록은 이 기기에 저장돼요.

        계정이나 인터넷 연결 없이 쓸 수 있고, 광고·분석 도구가 없어요. 기기 동기화는 직접 켤 때만 써요.

        전체 JSON 백업에 기록과 설정이 모두 들어가요. 연결 코드는 빠져요.

        설정을 읽을 수 없어 원본을 보관했어요. 전체 백업으로 복원하거나 설정 원본을 저장할 수 있어요. 원본에 개인 정보가 있을 수 있으니 공유에 주의해 주세요.

        중단된 복원과 다른 창의 변경이 겹쳐 기록을 보호하고 있어요. 다른 창을 닫고 복구 자료를 저장해 주세요. 자료에는 개인 정보가 포함될 수 있어요.

        기기 동기화

        기록을 이 기기에서 암호화해 올리고, 같은 코드를 넣은 기기끼리 맞춰요. 서버는 내용을 읽을 수 없어요.

        QR이 화면 안에 들어오게 맞춰 주세요.

        다른 기기에서 ‘QR로 연결’을 눌러 이 QR을 비추면 연결돼요.

        이 코드를 다른 기기의 ‘이 코드로 연결’에 입력하세요. 코드를 아는 사람은 기록을 볼 수 있으니 공유하지 마세요.

        Windows 실행트레이에서 계속 실행, 자동 실행

        식사 기록 내보내기

        JSON에는 식사·체중·활동·설정이, CSV에는 식사만 들어가요. AI 연결 코드는 빠져요.

        가져오기 방식

        바꾼 직후에는 되돌리기로 이전 기록을 복구할 수 있어요.

        단식 타이머 사용 방법

        처음 사용하기

        1. 식사를 마치면 아침·점심·저녁·간식 버튼을 눌러요. 누른 시각이 기록돼요.
        2. 가운데 타이머가 마지막 식사 이후 시간을 보여 줘요.
        3. 잘못 눌렀다면 되돌리기나 Ctrl + Z를 눌러요.

        휴대폰에서 쓰기

        아래 탭을 누르거나 좌우로 밀어 이동해요. 통계에서 날짜를 누르면 하루 칼로리를 볼 수 있어요.

        기록은 이 브라우저에 저장돼요. 기기를 바꾸기 전에 ‘기록 백업’에서 JSON을 저장하거나 ‘기기 동기화’를 켜 두세요.

        기록 보관

        기록은 이 컴퓨터의 %LOCALAPPDATA%\DansikTimer\data에만 저장돼요. 도움말 메뉴의 기록 폴더 열기로 열 수 있어요.

        개인정보

        계정·광고·분석 도구가 없고, 기록은 이 기기에 저장돼요. 음식 AI 계산이나 기기 동기화를 직접 켤 때만 해당 데이터가 서버로 나가며, 동기화 데이터는 암호화돼 서버가 읽을 수 없어요.

        단식 타이머는 시간을 기록하는 도구이며 의학적 조언을 제공하지 않아요.
